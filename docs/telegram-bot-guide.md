# 📱 Руководство: Telegram Bot Workflow (Human-in-the-Loop)

> **Назначение:** Спецификация мобильного рабочего места редактора в Telegram для согласования, редактирования и публикации постов без обязательного входа в Web Dashboard.

---

## 1. Концепция и Архитектура бота

Telegram Bot работает параллельно с `web-dashboard` и решает задачу **мгновенного согласования контента «на ходу»**:
* **Web Dashboard (`:3005`):** Полноразмерный интерфейс для детального мониторинга, аналитики и настроек порталов.
* **Telegram Bot:** Мобильный пульт управления: получение готовых превью постов, просмотр альбомов слайдов, быстрое редактирование текста и публикация в один клик.

```
+-------------------------------------------------------------+
|               OpenClaw: Run Awaiting Approval               |
+------------------------------+------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|                  Telegram Bot Notification                  |
|  1. Media Album (PNG-слайды карусели 1..6)                  |
|  2. Текст поста (Markdown) + Метаданные + Рейтинг SEO      |
|  3. Inline Keyboards (Интерактивные кнопки)                |
+------------------------------+------------------------------+
                               |
       +-----------------------+-----------------------+
       v                       v                       v
[ ✅ Опубликовать ]     [ 🔄 Рерайт ]           [ ✏️ Редактировать ]
(Status -> Publish)     (Cycle to Writing)      (Reply to message)
```

---

## 2. Формат уведомления о публикации

При переходе прогона в статус `awaiting_approval`:
1. **Альбом слайдов (`sendMediaGroup`):** Бот отправляет массив сгенерированных PNG-карточек карусели.
2. **Текст публикации (`sendMessage`):**
   ```text
   🎬 Готов новый пост для канала!
   
   Рубрика: Marvel & Geek Lore
   SEO Score: 92/100 | Alignment: 94%
   
   Заголовок: Где незаменим Testo 350? 4 ключевые сферы применения
   
   [Текст поста с форматированием, эмодзи и хэштегами]
   ```
3. **Клавиатура действий (`InlineKeyboardMarkup`):**
   * `[ ✅ Опубликовать сейчас ]` (`approve:<runId>`) — запускает публикацию в целевой канал.
   * `[ 🔄 Переписать текст ]` (`rewrite:<runId>`) — отправляет запрос на новую генерацию с другим хуком.
   * `[ 🎨 Сменить стиль дизайна ]` (`change_style:<runId>`) — переключает цветовую тему/шаблон.
   * `[ ✏️ Редактировать текст ]` (`edit_text:<runId>`) — включает режим ожидания текста от пользователя.
   * `[ ❌ Отклонить ]` (`reject:<runId>`) — отклоняет прогон.

---

## 3. Прямое редактирование через ответ на сообщение

Для быстрого исправления опечаток или изменения формулировок:
1. Пользователь нажимает кнопку `[ ✏️ Редактировать текст ]`.
2. Бот переходит в состояние ожидания и отвечает: «*Пришлите обновленный текст поста ответным сообщением (Reply)*».
3. Пользователь отправляет отредактированный текст.
4. Бот напрямую обновляет документ в `stage_results` (`stage: "writing"`) и перерендеривает карусель через Puppeteer за 6 секунд без вызова LLM.
5. Бот присылает обновленные слайды с подтверждением.

## 4. Команды Telegram-бота

### 📡 Интерактивные радары тем (Curators):
| Команда | Описание |
| :--- | :--- |
| `/daily_cinema` | Радар тем кино и Marvel (Популярные vs Свежие новости) |
| `/daily_tech` | Радар IT & Tech (Архитектура high-load, GitHub trending) |
| `/daily_testo` | Радар Testo Kazakhstan (Газоанализаторы ТЭЦ, Фармацевтика GxP) |

### ✍️ Создание постов по своей теме (Direct Launch):
| Команда | Описание |
| :--- | :--- |
| `/post_cinema <тема>` | Сгенерировать пост и карусель по теме кино |
| `/post_tech <тема>` | Сгенерировать пост и карусель по IT/Архитектуре |
| `/post_testo <тема>` | Сгенерировать пост и карусель по приборам Testo |

### ⚙️ Системные команды и мониторинг:
| Команда | Описание |
| :--- | :--- |
| `/status` | Статус последних прогонов по всем порталам |
| `/logs` | Журнал прогонов с детальными логами стадий |
| `/logs queues` | Нагрузка и количество задач в очередях BullMQ |
| `/test_pipeline` | Тестовый запуск генерации |
| `/help` | Справка по работе с ботом и списку команд |
