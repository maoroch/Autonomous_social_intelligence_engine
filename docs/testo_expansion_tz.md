# 📋 Техническое Задание (ТЗ): Расширение B2B-контента, Golden Dataset и внедрение новой рубрики для Testo

## 🎯 1. Цель задачи
Переориентировать контентный пайплайн портала **Testo** с общих регуляторных формулировок на **глубокий B2B-фокус** с детализацией практических сфер применения оборудования (фармацевтика, склады GDP, чистые помещения, микроклимат, поверка/калибровка) и внедрить новую специализированную рубрику — **«Разбор прибора Testo» (`testo-device-breakdown`)**.

## 📌 2. Новая контентная рубрика: `testo-device-breakdown`

### 2.1 Метаданные рубрики
- **`pillarId`**: `testo-device-breakdown`
- **Название (RU)**: «Прибор в деталях / Разбор оборудования Testo»
- **Целевая аудитория**: Главные инженеры, QA-директоры, руководители служб валидации и метрологи фарм-предприятий и складских комплексов.
- **Ключевой фокус**: Подробный разбор 1 конкретной модели (например, *Testo Saveris Pharma*, *Testo 174T*, *Testo 883*, *Testo 440*), её технических характеристик, решаемой B2B-боли, процесса интеграции в GxP-контур и окупаемости при аудитах.

### 2.2 Структура поста для рубрики `testo-device-breakdown`
1. **Hook (Заголовок)**: Название прибора + конкретная бизнес-проблема, которую он решает (например: *«Testo Saveris Pharma: Как исключить 100% ручных списаний на складе лекарств»*).
2. **B2B-Проблема / Промышленный сценарий**: Конкретный риск (авария кондиционирования, риск непрерывности данных, человеческий фактор при заполнении журналов).
3. **Технический разбор прибора**:
   - Точность измерений и диапазон.
   - Наличие встроенных интерфейсов (Ethernet/WLAN/Radio), Audit Trail, ERES compliance (21 CFR Part 11).
   - Избыточность логирования (память датчика + станция + сервер).
4. **Результат для B2B-клиента**: Готовность к инспекциям FDA/EMA/Минпромторга, снижение рисков списания брака на миллионы рублей, экономия времени инженеров.
5. **Call to Action (CTA)**: Заказ официального прибора у дистрибьютора с поверкой и внесенным реестром СИ.

## 🧠 3. Обновление системных промптов (`agent-writing` и `agent-strategy`)

### 3.1 Требования к промпту генерации постов Testo
Промпт должен строго требовать **B2B-сценариев использования**:
- Указывать конкретные типы помещений (холодильные камеры 2–8°C, морозильники -80°C, чистые помещения ISO 5..8, зоны разгрузки GDP).
- Указывать конкретные приборы из линейки Testo (*Testo Saveris*, *Testo 174T/H*, *Testo 184*, *Testo 883*, *Testo 440*).
- Приводить точные GxP-метрики (ALCOA+, ERES, Audit Trail, 21 CFR Part 11).
- Категорически запрещать абстрактные фразы («наше оборудование очень надежное») без указания модельного ряда и физических параметров.

## ✅ 6. Критерии приемки (Acceptance Criteria)

1. **Генерация постов новой рубрики**: При выборе темы `testo-device-breakdown` генератор выдает пост с глубоким разбором конкретного оборудования Testo (модель, характеристики, окупаемость).
2. **Отсутствие IT-тегов**: Ни в одном посте портала Testo не присутствуют хэштеги `#github`, `#backend`, `#softwareengineering`.
3. **B2B Контекст**: В постах упоминаются реальные промышленные объекты (чистые помещения, фарм-склады GDP, инспекции FDA/EMA, тепловизионный аудит).
4. **Golden Dataset Alignment**: Оценка соответствия `alignmentScore` в `agent-evaluator` для постов Testo составляет не менее 90%.
