# Техническое задание: Positioning Agent (Агент позиционирования)

## 1. Назначение
Positioning Agent фильтрует темы, найденные Trend Agent, оценивая их релевантность профилю автора. Его цель — пропустить только те темы, о которых автору действительно стоит писать, и отсеять нерелевантный шум.

## 2. Входные данные (Payload задачи)
Агент принимает на вход одну из тем и сравнивает её с профилем автора.
```json
{
  "runId": "uuid-string",
  "stage": "positioning",
  "attempt": 1,
  "payload": {
    "topic": {
      "title": "Заглушка: рост интереса к AI-агентам в backend-разработке",
      "summary": "Развернутое описание сути тренда...",
      "score": 80,
      "keywords": ["ai-agents", "node.js", "backend"],
      "sources": ["https://example.com"]
    },
    "authorProfile": {
      "topics": ["Node.js", "Next.js", "AI", "SaaS", "Backend", "Automation"],
      "forbidden_words": ["crypto", "web3", "nft"],
      "use_emoji": true,
      "tone": "expert"
    }
  }
}
```

## 3. Выходные данные (PositioningOutput)
Результат валидируется Zod-схемой `PositioningOutputSchema`:
```json
{
  "relevance": 94, // Процент соответствия профилю автора от 0 до 100
  "reason": "Тема напрямую затрагивает AI-агентов и backend-разработку на Node.js, что полностью соответствует ключевым топикам автора.",
  "accepted": true // Флаг: пропускаем ли тему дальше по пайплайну
}
```

## 4. Логика работы
1. **Trigger**: Получение задачи из очереди `QueueName.POSITIONING`.
2. **LLM Evaluation**:
   - Формирование системного и пользовательского промпта. В промпт передается тема (заголовок, описание, ключевые слова) и профиль автора (список разрешенных тем, интересы и запрещенные темы).
   - Модель просят проанализировать релевантность темы для блога автора.
   - Также просят проверить наличие запрещенных слов (`forbidden_words`). Если тема относится к запрещенным сферам, `accepted` должен быть выставлен в `false`.
3. **Structured Response**:
   - Модель должна вернуть JSON со свойствами `relevance`, `reason`, `accepted`.
4. **Validation & Next Steps**:
   - Проверка через `PositioningOutputSchema`.
   - Если `accepted: false`, Open Claw останавливает пайплайн для этой темы, фиксируя ее как отсеянную. Если `true`, переходит к следующему шагу (Strategy).
