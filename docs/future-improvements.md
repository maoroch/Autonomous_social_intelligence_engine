# Идеи по улучшению проекта (Future Improvements)

Ниже перечислены архитектурные идеи и функции для развития LinkedIn AI Content Pipeline до уровня коммерческого SaaS-продукта.

---

## 1. Автоматическая публикация (LinkedIn Publishing Agent)
* **Цель:** Исключить ручной перенос постов в LinkedIn.
* **Описание:** Добавить финальную стадию пайплайна — `PUBLISHING`. После одобрения публикации на дашборде, задача отправляется в очередь публикации. Специальный агент через LinkedIn API (или Puppeteer/Playwright при отсутствии API-доступа) публикует пост и загружает PNG-карусель.

## 2. Рендеринг реальных PNG-каруселей (Carousel Renderer)
* **Цель:** Генерация готового медиа-файла для загрузки.
* **Описание:** На основе JSON-структуры слайдов, сгенерированной `agent-design`, отрендерить слайды в PNG с помощью HTML/CSS шаблона и Puppeteer. PNG-файл сохраняется в MongoDB/S3 и доступен для скачивания или автопубликации.

## 3. Аналитический цикл обратной связи (Analytics Feedback Loop)
* **Цель:** Самообучение пайплайна на основе реальных метрик.
* **Описание:** Периодический сбор статистики просмотров, лайков и комментариев с опубликованных постов. Сохранение метрик в MongoDB. При генерации новых постов агенты `strategy` и `writing` учитывают историю наиболее успешных публикаций автора для корректировки тем и тона.

## 4. Панель управления профилями авторов (Multi-Author / Profiles UI)
* **Цель:** Обслуживание нескольких авторов в рамках одного инстанса.
* **Описание:** Перенос конфигурации автора (`topics`, `forbidden_words`, `cta_style`, `tone`, `color_schema`) из констант кода в MongoDB. Добавление веб-интерфейса для управления профилями разных авторов на дашборд.

## 5. Инлайн-редактирование перед подтверждением (Inline Editing)
* **Цель:** Быстрое исправление опечаток или тона перед отправкой в LinkedIn.
* **Описание:** Интеграция редактора контента прямо на детальную страницу прогона дашборда `/runs/[runId]`. Редактирование финального текста поста (Hook, Body, CTA) и содержимого карточек карусели с сохранением изменений в БД перед вызовом финального одобрения.
