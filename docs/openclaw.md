# Техническое задание: Open Claw Orchestrator (Оркестратор)

## 1. Назначение
Open Claw — это центральное ядро системы (Workflow Engine). Он не генерирует контент самостоятельно, а координирует работу всех агентов, управляет базой данных (MongoDB), контролирует очереди задач (BullMQ), обрабатывает ошибки, запрашивает ручное подтверждение от пользователя (Human Approval) и собирает финальный пакет для публикации.

## 2. Схема Жизненного Цикла Пайплайна (Pipeline Run Stages)
Процесс создания одной публикации проходит следующие стадии:

```
[INIT] 
  ↓
[TREND] (Trend Intelligence Agent)
  ↓
[POSITIONING] (Positioning Agent) -> если accepted == false, завершаем
  ↓
[STRATEGY] (Content Strategy Agent)
  ↓
[WRITING] (Writing Agent) <-------------------------┐
  ↓                                                 │ (Доработка при низком SEO score)
[DESIGN] (Design Agent)                             │
  ↓                                                 │
[SEO] (SEO Agent) ----------------------------------┘
  ↓ (Если score >= 80)
[AWAITING_APPROVAL] (Ожидание подтверждения от человека)
  ↓
[APPROVED] / [REJECTED]
  ↓ (Если Approved)
[PUBLISHED]
```

## 3. Обязанности Оркестратора

### 1. Управление очередями задач (BullMQ)
* Open Claw создает задачу для очередного шага, валидирует входные данные и помещает в очередь соответствующего агента (например, `queue:trend`).
* Слушает общую очередь событий `queue:pipeline:events`, куда все агенты возвращают статус выполнения (`completed` / `failed`).
* При получении события `completed` сохраняет промежуточный результат в БД и переводит пайплайн на следующий шаг.

### 2. Контроль ошибок (Fault Tolerance)
* Если агент сообщает о `failed` или задача падает по таймауту, Open Claw делает повторную попытку выполнения (`attempt++`) до `MAX_RETRIES_PER_STAGE` (по умолчанию 2).
* При превышении лимита ретраев прогон переходит в статус `failed` и отправляет уведомление.

### 3. Контроль качества (Quality Loop)
* После стадии `SEO` проверяется полученный `score`. 
* Если `score < 80`, Open Claw может вернуть задачу на стадию `WRITING`, приложив к `extraInstructions` рекомендации от `SEO Agent`.
* Допускается максимум $N$ итераций доработки (по умолчанию 2), чтобы избежать бесконечного цикла генерации.

### 4. Human Approval & Сборка пакета
* После успешного прохождения всех этапов Open Claw формирует пакет публикации:
  - Текст поста, hook, CTA.
  - Описание дизайна и данные рендеринга карусели.
  - Источники информации и SEO score.
* Переводит статус в `awaiting_approval` и ожидает действия от пользователя через Dashboard (события `approve` / `reject`).
