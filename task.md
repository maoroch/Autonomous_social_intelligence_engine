# Техническое задание: Медиа-портал о кино и сериалах (Marvel / Cinema Hub) + Telegram Bot Workflow

> **Назначение документа:** Полноценное ТЗ для ИИ-агента (Jules / Copilot / Developer) по развертыванию нового автономного медиа-портала `cinema-media` и расширению взаимодействия через Telegram Bot (полный цикл генерации, модерации и публикации через бота без необходимости заходить в Web Dashboard).

---

## 🎯 1. Концепция и цели

1. **Новый портал (`tenantId: "cinema-media"`):**
   - Ежедневное автономное медиа о новостях кино, сериалов, киновселенной Marvel (MCU), гик-культуры, истории создания культовых фильмов и аналитике кассовых сборов.
   - Полноценная работа ИИ-агента `agent-trend` на открытых динамичных источниках (Reddit, RSS Variety/Deadline/THR) в автономном ежедневном режиме (CRON).
2. **Telegram Bot как основной интерфейс (Human-in-the-Loop):**
   - Веб-дашборд (`web-dashboard`) остаётся нетронутым как вспомогательный инструмент.
   - Весь операционный пайплайн для кино-медиа (уведомления, превью каруселей, согласование, регенерация, быстрая правка текста и публикация) переносится в **Telegram Bot** с интерактивными кнопками (Inline Keyboards).

## 🤖 3. Настройка AI-агентов для Кино-портала

### 3.1. `agent-trend-intelligence` (Поиск инфоповодов)
* **Источники (Sources):**
  * **Reddit API / Scraper:** `r/marvelstudios`, `r/movies`, `r/boxoffice`, `r/television`, `r/Marvel`.
  * **RSS-ленты ведущих киноизданий:**
    * *Variety* (`https://variety.com/feed/`)
    * *The Hollywood Reporter* (`https://www.hollywoodreporter.com/feed/`)
    * *Deadline* (`https://deadline.com/feed/`)
    * *Collider* (`https://collider.com/feed/`)
  * **Google Trends:** Категория «Entertainment / Movies».
* **Периодичность:** Автоматический ежедневный запуск в 08:00 и 18:00 (настраивается через BullMQ / CRON).

### 3.2. `agent-positioning` & `agent-strategy`
* **Критерии отбора:** Уровень виральности (Hype Score), эмоциональный накал, отсутствие откровенных фейков/пустых слухов.
* **Форматы подачи:** «10 скрытых деталей», «Почему Marvel меняет планы», «Как снимали культовую сцену», «Бюджет против сборов».

### 3.3. `agent-writing` (Копирайтинг)
* **Tone of Voice:** Динамичный, вовлекающий, гик-журналистика, легкий сторителлинг с интригующими хуками и вопросом/дискуссией в CTA.
* **Изоляция:** В промпты кино-рубрик не должны попадать инструкции от `testo` или `tech`.

### 3.4. `agent-design` (Визуальный стиль каруселей)
* **Новый стиль шаблона (`template_name: "cinema-dark-neon"`):**
  * Цветовая палитра: глубокий темный фон (`#0D0E12`, `#14171F`), неоновые акценты (красный Marvel `#E23636`, золотой для классики кино `#FFB800`, Sci-Fi циан `#00D2FF`).
  * Элементы: бейджи Фаз Marvel, шильдики рейтингов IMDb / Кинопоиск, постерная контрастная типографика, плашки для цитат и фактов.

## 📱 4. Спецификация Telegram Bot Workflow (Замена Dashboard)

Telegram-бот становится главным пультом управления редактора.

```
                  ┌──────────────────────────────────────────────┐
                  │ 1. OpenClaw Pipeline: Run Awaiting Approval  │
                  └──────────────────────┬───────────────────────┘
                                         │
                                         ▼
                  ┌──────────────────────────────────────────────┐
                  │ 2. Bot sends Telegram Notification to Admin │
                  │    - Slide Deck as Media Album (PNGs)        │
                  │    - Formatted Post Copy + Hashtags          │
                  │    - Interactive Inline Keyboard             │
                  └──────────────────────┬───────────────────────┘
                                         │
          ┌──────────────────────────────┼──────────────────────────────┐
          ▼                              ▼                              ▼
┌───────────────────┐          ┌───────────────────┐          ┌───────────────────┐
│  [✅ Опубликовать]  │          │   [🔄 Рерайт]     │          │  [✏️ Текст в ответ] │
│  Triggers Publish │          │   Re-runs writing │          │  Direct edit in DB│
└───────────────────┘          └───────────────────┘          └───────────────────┘
```

### 4.1. Формат уведомления о готовом посте
Когда статус прогона переходит в `awaiting_approval`:
1. Бот отправляет **Media Group (альбом фото)** со всеми сгенерированными слайдами карусели (от 1 до 6 слайдов).
2. Бот отправляет сообщение с текстом поста (Markdown) + метаданными (Рубрика, Прогноз охвата, SEO/Alignment Score).
3. Прикрепляется интерактивная клавиатура (`InlineKeyboardMarkup`):
   ```
   [ ✅ Опубликовать сейчас ]
   [ 🔄 Переписать текст ]  [ 🎨 Сменить стиль дизайна ]
   [ ✏️ Редактировать текст ]  [ ❌ Отклонить прогон ]
   ```

### 4.2. Обработка действий (Callbacks & Handlers):
* **`✅ Опубликовать` (`approve_run:<runId>`):**
  * Бот переводит прогон в `publishing` (отправка в Telegram-канал / соцсети).
  * Редактирует сообщение: «*🚀 Пост успешно опубликован в канале @cinema_hub!*».
* **`🔄 Переписать текст` (`regenerate_writing:<runId>`):**
  * Запрашивает опциональный комментарий (что изменить) или делает рерайт с новым хуком.
* **`✏️ Редактировать текст` (`edit_text:<runId>`):**
  * Бот ждёт следующее текстовое сообщение от пользователя и напрямую обновляет `STAGE_RESULTS.writing` в MongoDB, после чего мгновенно обновляет превью.
* **`❌ Отклонить` (`reject_run:<runId>`):**
  * Прогон помечается как `rejected`.

### 4.3. Команды Telegram-бота для ручного управления:
* `/daily_cinema` — запустить внеочередной авто-поиск трендов и генерацию для кино-портала.
* `/trends` — показать топ-5 трендов кино за сегодня с кнопками «*Создать пост по этому тренду*».
* `/post_topic <тема>` — создать пост по свободной теме (например: `/post_topic Секретные войны Marvel: кого вернут из старого каста`).
* `/status` — список последних прогонов и их статусы.

## 📋 5. Пошаговый план реализации для Jules

### Этап 1: Данные и Мультиарендность (Database & Seed)
1. Добавить сид организации `cinema-media` в `services/openclaw/src/scripts/seed-organizations.ts`:
   - `tenantId: "cinema-media"`
   - `name: "Кино и Marvel Медиа"`
   - `industryProfile: { language: ["ru"], glossary: ["MCU", "камео", "посткредиты", "бокс-офис", "пасхалка", "шоураннер"] }`
2. Завести рубрики (`content_pillars`) для `cinema-media`.
3. Добавить Golden Dataset примеры для валидатора `agent-evaluator`.

### Этап 2: Тренды и Скрапинг (`agent-trend`)
1. Создать кино-модуль скрапера в `services/agent-trend-intelligence/`:
   - Reddit RSS/JSON fetcher (`r/marvelstudios`, `r/movies`, `r/boxoffice`).
   - RSS-парсер для Variety, Deadline, Hollywood Reporter.
2. Подключить фильтрацию кино-новостей при `tenantId === "cinema-media"`.

### Этап 3: Промпты и Стили дизайна (`agent-writing` & `agent-design`)
1. В `agent-writing` настроить Tone of Voice для `cinema-media` (сторителлинг, живой язык, киноманский сленг).
2. В `agent-design` создать HTML/CSS шаблон `cinema-dark-neon` (тёмная кинематографичная тема, неоновые плашки, стильные бейджи).

### Этап 4: Telegram Bot Integration (Bot Service)
1. Реализовать/доработать сервис бота (в `services/agent-publishing/` или отдельном воркере `telegram-bot`):
   - Обработчики команд `/daily_cinema`, `/trends`, `/post_topic`.
   - Webhook / Polling для сообщений администратора.
   - Отправка Media Album слайдов карусели + Inline-кнопки одобрения.
   - Обработчик inline-кнопок (Approve $\rightarrow$ Publish, Regenerate, Edit).

### Этап 5: Проверка и Тестирование
1. Выполнить сидинг: `npx tsx services/openclaw/src/scripts/seed-organizations.ts`.
2. Запустить тестовый прогон через команду бота или API:
   ```bash
   curl -X POST http://localhost:4000/runs \
     -H "Content-Type: application/json" \
     -d '{
       "tenantId": "cinema-media",
       "targetPillarId": "marvel-mcu-lore",
       "topic": {
         "title": "5 скрытых деталей в новом трейлере Мстителей, которые меняют всё",
         "summary": "Разбор покадровых деталей, возвращение культовых персонажей и связь с комиксами Secret Wars."
       }
     }'
   ```
3. Убедиться, что в Telegram-бот пришло превью карусели с кнопками, и при нажатии «✅ Опубликовать» статус меняется на `completed` с отправкой в канал.
